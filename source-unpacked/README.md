# Aether extracted contents

The compressed input `aether-src-latest.aaf.gz` was decompressed and identified as **tar**. Files were extracted by GitHub Actions.

- `ARCHIVE-MANIFEST.tsv`: inventory of every extracted file and its size.
- `SOURCE-CANDIDATES.txt`: likely source/build files detected by filename.
- `files/`: extracted files small enough and suitable for Git storage; large disk images and compressed files are excluded.

This inventory does not assume that every file in the payload is source code; inspect the candidate list and README/build metadata before development.
